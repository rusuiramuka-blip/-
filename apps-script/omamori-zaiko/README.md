# 御守在庫 — 現場向けのレイアウト整理（スプレッドシートのまま）

沖縄・久留米の御守在庫ファイルを、アプリを使わずスプレッドシートのまま見やすくする。
考え方は `docs/omamori-shogatsu-redesign.md`。

| ファイル | 何をするか | 実行 |
|---|---|---|
| `00_レイアウト整理.gs` | タブの並び・色、00_入口の作り直し、正月シートの見出しの色と列の固定 | 1回（何度実行しても同じ） |
| `01_取り置き一覧の自動入力.gs` | 取り置き一覧で「状況」「お支払い」を選ぶと、同じ受付の商品をまとめて更新 | 1回有効にすると以後ずっと |

シート名・列の並び・数式・入力済みの値は変えない。

## 導入（管理者・PC で）

1. **在庫ファイルのコピーを取り、まずコピーで試す。**
   （沖縄は Drive にある「沖縄御守在庫_正月操作_動作確認用_20261019」でもよい）
2. 在庫ファイルの「拡張機能 > Apps Script」を開き、左の「＋ > スクリプト」で
   2つのファイルを追加して貼る。**既存のファイルは消さない・書き換えない。**
   関数名はすべて `御守_` で始まり、既存の `onOpen` / `onEdit` とはぶつからない。
3. 上の関数選択で `御守_確認だけする` → ▶。ログに「見つからないシート」が出るので確認する
   （その拠点にないシートは飛ばすだけなので、出ていても問題ない）。
4. `御守_レイアウトを整える` → ▶（初回は許可画面が出る）。
5. `御守_取り置きの自動入力を有効にする` → ▶。
6. 下の「確認すること」を見て問題なければ、本番ファイルでも 2〜5 を行う。

## 確認すること

- タブが左から **緑（職員）→ 赤（正月）→ 青（管理者）→ 灰（分析）** の順になっている。
- 00_入口の「開く」をすべて押して、正しいシートが開く。
  元の入口は `00_入口_整理前_日付` という名前で非表示で残っている。
- 正月の準備シート・取り置き一覧の見出しが、黄＝入力する列、灰＝自動の列になっている。
  横に送っても商品名・お名前が見えている。
- 取り置き一覧で、2商品ある受付の1行の「状況」を「取り分け済み」にすると、
  もう1行も変わり、「取り分けた数」が入る。「お渡し済み」にするとお渡し日が入り、
  受取時払いなら支払済みになる。**スマホのスプレッドシートアプリでも同じ動きになる**か。
- 準備シートの「うち取り置き中」（沖縄）／「取り置き確保数」（久留米）の数が想定どおりか。

## 戻し方

- 自動入力を止める: `御守_取り置きの自動入力を止める` を実行。
- 入口を戻す: `00_入口_整理前_日付` を表示 → 名前を `00_入口` に変える（今の入口は削除）。
- タブの色・並び・見出しの色は手で戻す（値や数式は変わっていない）。

## 注意

- 取り消しは **商品ごと**（1商品だけ取り消すことがあるため、同じ受付の他の行には広げない）。
- 「お渡し済み」を戻すと、お渡し日は消えるが、自動で付けた「支払済み」はそのまま。
  支払っていなかった場合は「お支払い」も選び直す。
- 貼り付けや複数セルの一括変更では動かない（1セルずつ選んだときだけ）。
- 在庫ファイル側のスクリプトに、入口や見出しを作り直す処理がある場合は、
  そちらを実行すると今回の見た目が上書きされる。そのときは `御守_レイアウトを整える` をもう一度。
