# 巫女勤怠・シフト・給与 Apps Script（修正版）

診断（`docs/miko-payroll-audit.md`）と設計（`docs/miko-slot-design.md`）を、実際に動くコードに反映したもの。

## 構成

```
apps-script/
  genba/            現場用ファイルに貼る（1jIb8Z72...）
    00_共通.gs       定数・ユーティリティ・メニュー
    01_シフト入力.gs  自動数式・編集監視・枠の自動生成
    02_募集状況.gs    02B_募集状況 の作成
    03_配置グリッド.gs 04_日別30分配置 を入力画面にする
    04_当日勤怠.gs    予定どおり反映／欠勤／実績の給与送信
    05_給与連携.gs    確定シフトの送信・初回設定
    06_貸与品.gs      襦袢台帳
    07_移行.gs        一度だけ実行する移行処理
  kyuyo/            管理者用ファイルに貼る（1GOBCBEl...）
    00_給与.gs        承認・締め・支給・受領
    01_数式と共通.gs   計算式の復元・ユーティリティ
```

> **2つのフォルダは必ず別の Apps Script プロジェクトに置くこと。**
> `onOpen` `onEdit` `requireSheet_` などが同名なので、1つのプロジェクトに
> 同居させると後から読まれた定義が勝って静かに壊れる。

## 導入手順

### 0. 準備

1. 両方のスプレッドシートの**コピーを取る**（ファイル > コピーを作成）。
   移行処理は行数・列・数式を書き換えるため、戻せるようにしておく。
2. 各ファイルの「拡張機能 > Apps Script」で、
   `appsscript.json` に `"timeZone": "Asia/Tokyo"` を明示する。
   （`Session.getScriptTimeZone()` は常に値を返すのでコード側のフォールバックは効かない）

### 1. 管理者用（給与）

1. `kyuyo/` の2ファイルを貼る。
2. `setupAndCheck` を1回実行。
3. 必要に応じて `repairAttendanceFormulas` で計算式を復元。

### 2. 現場用

1. `genba/` の8ファイルを貼る。
2. **`migrate_00_全部まとめて` を1回だけ実行**（確認ダイアログが出る）。
   - 02_シフト入力・02A_当日勤怠 を 3,000 行、03_配置変更 を 1,000 行へ拡張
   - 数式の参照範囲を新しい行数に合わせる（**参照先シート名を見て判定**するので、
     行を増やしていない 07_必要人数 の `$304` などは書き換えない）
   - 02_シフト入力 に V列「時間帯」、01_スタッフ に I列「メールアドレス」を追加
   - 勤務IDを行番号依存の数式から静的値へ
   - 09_申込・02B_募集状況 を作成
   - 03_配置変更 の I列を、深夜枠の日跨ぎに対応した式へ差し替え
   - 04_日別30分配置 のグリッドを 80 行にし、勤務ID列を静的値へ
3. `checkRemainingOldRanges` で、旧上限のままの数式が残っていないか点検。
4. 「初回設定・接続確認」→「期間の枠を作成」→「募集状況を作り直す」。

### 3. 移行後に手で直す箇所

- **04_日別30分配置 の不足マトリクス**（旧61〜73行）が `B$6:B$57` を数えているので、
  参照を `B$6:B$85` に直す。行を増やしたぶん下にずれている点も確認する。
- **02B_募集状況** の条件付き書式はスクリプトが設定するが、色を変えたい場合は
  `applyRecruitFormatting_` を編集する。
- **_設定 に「明細フォルダID」を追加**すると、給与明細PDFを専用フォルダへ出力できる。
  未設定だとスプレッドシートと同じ場所に作られ、そのフォルダの共有範囲を継承する。

## 新しくできること

- **期間の枠を作成** — `07_必要人数` から担当者を空欄にした仮枠をまとめて作る。
  何度実行しても不足ぶんしか増えない
- **02B_募集状況** — 34日分の不足を1画面で。赤＝不足、黄＝あと少し、緑＝充足
- **この日の配置表を開く／配置を保存** — `04_日別30分配置` を配置の入力画面に。
  塗ると不足マトリクスがその場で動く。時刻は書き換えない（9:00–16:10 のような枠を壊さない）
- **予定どおりを反映／欠勤にする／枠を再募集する／担当者を交代** — 当日の操作を1タップに。
  「枠を再募集する」は担当者だけ外して枠を残すので、募集に戻る
- **09_申込** — 担当者の増減をすべて記録。ウェブアプリを足すときもここへ書く

## まだ実装していないもの

- **巫女用ウェブアプリ**（設計 ②）。`09_申込` と `appendApplyLog_` は先に用意してあるので、
  `doGet`/`doPost` を足せば繋がる。18歳未満の深夜ブロック・時間重複の判定・
  `LockService.getScriptLock()` での定員制御が必須
- **週40時間超・法定休日の割増**（設計 C-6）。現状は日8時間超のみ
- **源泉所得税の自動計算**（日額表・丙欄）。いまは手入力のまま、未判定なら締められないだけ

## 注意

- `04_日別30分配置` は「開く → 塗る → 保存」。開かずに塗っても保存されない
- 保存時に「読み込んだ後に他の方が変更しています」と出たら、開き直してから保存する
- 現場担当が給与ファイルへ書き込むため、現在も現場アカウントに管理者ファイルの
  編集権限が必要（設計 C-1）。本番では管理者所有のウェブアプリを挟むこと
