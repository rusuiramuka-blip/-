# 御守在庫（正月・取り置きを含む）を現場で見やすくする

対象: 沖縄御守在庫_商品マスタ / 久留米御守在庫_商品マスタ
（2026/10/21 時点のシートを読んで整理。**スプレッドシートでの管理を前提**とし、アプリは使わない）

実装: `apps-script/omamori-zaiko/`

## いま分かりにくい理由

1. **表示中のシートが多く、並びがばらばら。** 沖縄13枚・久留米14枚。
   01 → 新商品検討 → 13 → 14 → 02 → 06 → 03 → 07 → 08 と、分析用が日常用より前にある。タブの色もない。
2. **00_入口の「開く」が押しても開かない行が多い。**
   沖縄: 発注管理・取り置きを受け付ける・仕入分析。久留米: ほぼすべて。
   「管理者用検索」が【職員用メニュー】に入っている。
3. **正月の取り置きが分かれている。** 沖縄は 受付票（08-1）／一覧（08-2）／準備（08）の3枚で、
   一覧の操作は「行を選んでメニュー」。メニューは **スマホのスプレッドシートアプリでは動かない**。
4. **正月の準備シートが横に30列。** 入れる列と自動の列の見分けがつきにくい。
   久留米は列が固定されておらず、横に送ると商品名が消える。
5. **00_使い方が108行。** 職員が知りたいのは数場面の手順だけ。

## 直し方

### 1. タブを使う人ごとに並べ、色を付ける

| 色 | グループ | シート（左から） |
|---|---|---|
| 緑 | 職員がふだん使う | 00_入口 / 02 職員用スマホ検索 / 00_使い方 |
| 赤 | 正月 | （沖縄）08-1 受付 / 08-2 一覧 / 08 準備　（久留米）08-2 / 08 |
| 青 | 管理者 | 02 管理者用検索 / 06 発注管理 / 07 発注履歴 / 01 商品マスタ / 03 在庫増減履歴 / 十二支守護本尊入力 |
| 灰 | 分析 | 13 仕入分析 / 14 授与額分析 / 新商品検討 |

職員には「**緑のタブだけ使う**」と伝えればよくなる。
正月の3枚は赤でひとかたまりにし、受付 → 一覧 → 準備 の作業順に並べる。

### 2. 00_入口を作り直す

- すべての「開く」を、そのファイルのシートへ正しくつなぐ（シートの ID から自動で作る）。
- 上から「ふだん使う」「正月」「管理者」「分析・ほか」。見出しはタブと同じ色。
- 下に **職員がよく使う手順**（売場へ出した／納品された／戻した／破損／正月の取り置き／正月中の注意）を
  1行ずつ載せる。職員は 00_使い方を開かなくても済む。00_使い方は管理者向けの詳しい説明として残す。
- 今の説明文・フォームのリンク・祈願札のリンク・運用方針（※の行）は引き継ぐ。元の入口は非表示で保存。

### 3. 取り置き一覧は「状況を選ぶだけ」にする

一覧の「状況」（沖縄: 準備待ち／取り分け済み／お渡し済み、久留米: 受付／確保済／受渡済）を
プルダウンで選ぶと、

- 同じ受付番号の商品がまとめて同じ状況になる
- 取り分け済み: 取り分けた数が入る
- お渡し済み: お渡し日が入り、受取時払い・未入金は支払済みになる

セルの編集で動く仕組みなので、**スマホのスプレッドシートアプリでも動く**。
行を選んでメニューを探す必要がなくなる（メニューも今までどおり使える）。

現場での流れ:

| 場面 | すること |
|---|---|
| 取り置きを受ける | 沖縄: 08-1 に記入して「受付を登録する」／久留米: 08-2 に1商品1行で記入 |
| 品物を袋に分けた | 一覧でその方の「状況」を **取り分け済み** に |
| お渡しした | 「状況」を **お渡し済み** に（代金を受け取った場合も同時に記録される） |
| 1商品だけやめた | その行だけ **取消** |

一覧のフィルタで「状況」を絞れば、「まだ取り分けていない人」「お渡し前の人」だけを出せる。

### 4. 正月シートの見出しを色分けし、列を固定する

- 見出しの色: **黄＝入力する列**、**灰＝自動計算（触らない）**。2行目に式があるかで自動判定。
- 商品名・お名前（D列）まで固定し、横に送っても何の行か分かるようにする（久留米の準備シート）。

## 今回は変えないもの

- シート名・列の並び・数式・入力済みの値。在庫ファイル側の既存スクリプト（正月のお守りメニューなど）。
- 沖縄の 08-1 受付票は残す（お名前を一度で複数商品を登録できる利点があるため）。

## あわせて検討したいこと（今回の実装には含めない）

- **久留米の正月の計算**: `正月確保数(R) = 本堂数 + 下受付数 + 取り置き確保数` と、取り置きを準備数に足している。
  沖縄は「取り置きは準備数の内訳で、足さない」に直してある。久留米のままだと終了後の正月販売数が
  取り置きぶん多く出るおそれがある。在庫ファイル側のスクリプトを沖縄と同じ版にそろえたい。
- **久留米の準備シートの式の範囲**: 取り置き一覧を 689 行目までしか数えていない（一覧は1000行）。
- **シート名と言葉を両拠点でそろえる**（08_正月管理 と 08_正月の準備・片付け など）。
  既存スクリプトがシート名で動いているため、スクリプトを確認してから行う。
