# 正月のお守り（準備・取り置き）を現場で使いやすくする

対象: 沖縄御守在庫_商品マスタ / 久留米御守在庫_商品マスタ
（2026/10/21 時点のシートを読んで整理）

## いま分かりにくい理由

沖縄には正月用のシートが3枚ある。

| シート | 中身 | 使う人 |
|---|---|---|
| 08_正月の準備・片付け | 商品ごとの予定・準備・終了後の残り（30列） | 管理者 |
| 08-1_取り置き受付 | セルに書く受付票。チェックを入れると登録 | 受付担当 |
| 08-2_取り置き一覧 | 受付の台帳。行を選んでメニューで操作 | 受付担当 |

1. **「取り置き」が2枚に分かれている。** 書く場所（08-1）と見る・操作する場所（08-2）が別で、
   「受け付けたあとどこを見るのか」が分からなくなる。取り置きは正月にしか使わないのに、
   正月の準備シートとも並んで3枚になっている。
2. **操作がメニュー頼み。** 一覧で行を選んで「拡張メニュー > 正月のお守り > …」を選ぶ方式は、
   **スマホの Google スプレッドシートではメニューもチェックボックスのスクリプトも動かない**。
   本堂や屋外の現場で使えるのは PC だけになる。
3. **1枚に全工程の列が並ぶ。** 予定・準備・期間中・終了後の列が横に30列並び、
   いまどの欄を入れる場面なのかが列名からしか分からない。
4. **拠点で言葉と計算が違う。** 状態は 沖縄「準備待ち・取り分け済み・お渡し済み」／
   久留米「受付・確保済・受渡済」。久留米は取り置き数を準備数に **足す**、沖縄は **足さない**。

## 直し方の方針

**シートは「管理者の表」、現場は「1つの画面」に分ける。**

```
管理者（PC）                     現場（スマホ・タブレット・PC）
08_正月の準備・片付け            正月のお守り 画面（1つのURL）
  予定数・準備完了                ① 受付        お名前＋商品をまとめて登録
                                  ② お渡し      さがす → 取り分けた → お渡しした
08-2_取り置き一覧（台帳）  ◀──── 取り分け表   まだ取り分けていない数を商品ごとに
                                  ③ 残りを数える 本堂・屋外・取り置きの残数
```

- 現場が開くのは **画面1つ** だけ。シートを切り替えない、行を選ばない、メニューを探さない。
- シートは **2枚**（正月の準備、取り置き一覧）になる。08-1 は非表示にする。
- 取り置き一覧の列や式は変えない。画面は、いまの一覧にそのまま書き込む。
  正月の準備シートの「うち取り置き中」などの式もそのまま動く。

## 正月の流れ（現場の手順）

| 時期 | 場面 | 画面でやること |
|---|---|---|
| 11〜12月 | 予定を決める（管理者） | 準備シートに本堂・屋外の予定数（いまのまま） |
| 受付期間 | 取り置きを受ける | ① お名前 → 商品を検索してタップ → 数量 → 登録。受付番号が大きく出るので控えを渡す |
| 年末 | 品物を揃える | 取り分け表で商品ごとの合計を見て揃える → ② で受付ごとに「品物を取り分けた」 |
| 正月 | お渡し | ② で名前か番号をさがす → 「代金を受け取って お渡しした」 |
| 正月明け | 残りを数える | ③ 場所を選び、商品ごとに − ＋ で残数 → 保存。3か所そろうとお渡し数が出る |

間違えたら「ひとつ前に戻す」。取り消しは「取り消す」（品物は売場へ戻す）。

## 画面でできるようにしたこと

- **商品の検索**: 名前の一部・カテゴリー・商品番号で。ひらがな/カタカナ、半角/全角を区別しない
  （久留米の `ｷｰﾎﾙﾀﾞｰ` も「キーホルダー」で出る）。正月対象を先に表示。
- **二重登録の防止**: 登録ボタンを2回押しても、通信が切れて再送しても1件だけ。
- **受取日が過ぎた取り置き** を赤で表示。「今日受取」で当日分だけを出せる。
- **お支払い**: 受取時払いの人は、お渡しボタンが「代金を受け取って お渡しした」になり、金額を確認してから記録。
- **取り置きの残り**: ③ で「取り置き」を数えるとき、未受取の取り置き数を目安として表示。
- **控え・取り分け表の印刷**: ブラウザの印刷でそのまま出せる。

## 久留米の計算（あわせて直したいこと）

久留米の `08_正月管理` は、`正月確保数(R) = 本堂数(O) + 下受付数(P) + 取り置き確保数(Q)`。
沖縄は「取り置きは準備した数の内訳。別に足さない（100個準備して10個取り置き → 準備は100個）」に直してある。

久留米のままだと、取り置きを取り分けるたびに準備数が増えて見え、
終了後の「正月販売数」も取り置きぶん多く出るおそれがある。
在庫ファイル側のスクリプト（正月のお守りメニュー）を沖縄と同じ版にそろえるのがよい。
この画面は両方の計算で動く（書くのは取り置き一覧と残数だけ）。

## まだやっていないこと

- 予定数・準備完了の入力は画面に入れていない（管理者が PC で行う作業のため）。
- 在庫ファイル側のスクリプトはこちらから読めないため、沖縄の「正月のお守り」メニュー ② と
  セルの受付票（08-1）はそのまま残る。非表示にして使わない運用にする。
