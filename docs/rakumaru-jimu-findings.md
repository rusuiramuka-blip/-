## 2. 構造

**申込者（整理番号）1 : N 祈願者（申込番号）**

- 申込者 … 案内状・請求・領収書の相手。家名／施主名／会社名／〒／住所／電話／FAX／携帯／備考
- 祈願者 … 札に書く名前。会社名／役職／敬称／氏名／フリガナ／〒／住所／電話

これがそのまま「**案内と祈願者名は必ずしも一致しない**」の構造。
申込者は `90`／`91` へ、祈願者は `94_祈願・御札明細` へ入る。

1申込あたりの祈願者数の分布（5000円ファイル）：1名5件／2名6件／…／**24名1件**。
5000〜15000 でも最大11名。**内札は1申込に何枚も出るのが普通**で、
井町家6名は例外ではなかった。

## 3. 入力率（住所・電話が実用水準）

340申込のうち 住所302／電話249。フリガナもほぼ入っている。
前札（50000）ファイルは祈願者側の住所・電話も140前後入っている。

## 4. 注意点

- **金額・願意・祈願日・入金の列がない。** 金額はファイル（クエリ）の分け方でしか分からない。
- **整理番号はファイルをまたぐと別番号。** 同じ方が複数の祈願料で申し込んでおり、
  名前で照合すると65件の重なりがある（原口新五＝25000と50000、赤星寿美子＝3ファイル）。
  名寄せは名前で行い、職員が確認する必要がある。
- 申込者家名は38件だけ（5000〜15000）。世帯の単位に使えるか要確認。
