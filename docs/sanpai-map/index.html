成田山久留米分院

正月の参拝順路

図の向き：幸福階段から本堂を見た向き（手前が階段下）

1階段下に並ぶ

幸福階段の下が列の最後尾です。裏駐車場からの方もここへお並びください。

2右側を上る

幸福階段は右側が上りです。左側はお帰りの方が下ります。

3列の分岐

お参りのみの方はそのまま本堂参拝列へ。線香・ローソクをお供えの方は右の列へ。

4本堂でお参り

右入口から入り、堂内の賽銭箱でお参りください。お帰りは左出口から。

5お帰り

諸札授与所（お守り・おみくじ）の前を通り、幸福階段の左側を下ります。

お供えのあと本堂前階段で参拝列に合流し、本堂の右入口からお入りください。
裏駐車場から本堂と仏塔の間を通り、⑤から階段下①へ進んで列にお並びください。
設営用の略図です。テント・コーン・おみくじ売場の位置と、お供え後の合流位置は目安です。
