成田山久留米分院

正月の参拝順路

図の向き：幸福階段から本堂を見た向き（手前が階段下）

1階段下に並ぶ

幸福階段の下が列の最後尾です。裏駐車場からの方もここへお並びください。

2右側を上る

幸福階段は右側が上りです。左側はお帰りの方が下ります。

3列の分岐

古札・線香ローソクの方は右のテントへ。それ以外の方は本堂参拝列へ。

4本堂でお参り

本堂前階段を上り、正面の賽銭箱でお参り。右入口から本堂内に入り、左出口へ。

5お帰り

諸札授与所（御守・縁起物）の前を通り、幸福階段の左側を下ります。

テントでは手前が古札納所、その奥が線香・ローソクの授与です。古札のみの方は、納めたあと本堂参拝列へお進みください。
お供えのあと参拝列に並び直さず、右入口から直接本堂内に入り、堂内の賽銭箱の前でお参りいただけます。
授与・拝観御守・縁起物は諸札授与所と本堂内で、おみくじは観音様側の授与所で。観音様の拝観は登竜門の受付へ。
裏駐車場から本堂と仏塔の間を通り、⑤から階段下①へ進んで列にお並びください。
設営用の略図です。テント・コーン・おみくじ売場の位置と、お供え後の合流位置は目安です。
